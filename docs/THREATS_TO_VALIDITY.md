# Threats to Validity

## Construct validity

### Does categorical conclusion equality measure reconciliation?

The primary witness predicate treats a hybrid as sufficient when its categorical conclusion equals the target publication's conclusion. This is useful when the practical dispute concerns a winner or `INCONCLUSIVE` label, but it can hide large differences in effect magnitude, uncertainty width, or category-specific behavior.

**Mitigation:** report target-effect distance, restoration, category diagnostics, and optional effect-matching objectives separately. Do not describe categorical equality as numerical reproduction.

### Are protocol coordinates the right explanatory units?

A coordinate such as `reasoning_budget` can bundle several implementation changes. Conversely, one conceptual change may be split into several low-level fields. Minimum cardinality depends on this representation.

**Mitigation:** version and justify the protocol schema, report costs where cardinality is misleading, preserve alternative defensible schemas as sensitivity analyses, and avoid causal language.

### Does “minimum” imply importance?

A singleton witness is not necessarily the most important or largest-effect protocol change. It is only the smallest exposed substitution meeting the declared sufficiency predicate.

**Mitigation:** keep cardinality, effect restoration, nuisance sensitivity, robustness, and cost as different quantities.

### Is “witness” misleadingly legal or causal?

The term can sound stronger than the mathematics.

**Mitigation:** define it immediately as an executable finite counterfactual witness and state that it does not establish historical cause, fault, fraud, or universal model superiority.

## Internal validity

### Synthetic fixture calibration

The canonical world was designed to contain a useful disagreement and a known minimum witness. Even without direct answer branches, parameter selection can favor the intended story.

**Mitigation:** treat the canonical case as a tutorial/regression fixture; use independently generated landscapes, exhaustive Boolean model checks, frozen external grids, and future held-out real disputes for evidence.

### Shared implementation bugs

Builder, reconciler, certificate, and verifier code can agree because they share a defect.

**Mitigation:** independent known-ground-truth oracles, exhaustive three-coordinate model checking, a separate certificate reference oracle, mutation/tamper tests, and eventual independent-language reproduction.

### Source endpoint circularity

Canonical publications and counterfactuals are regenerated from the same bundled evaluator. This demonstrates self-consistency, not independent publication truth.

**Mitigation:** distinguish executable canonical replay from static external packages and require independently anchored evaluator/publication identities for stronger claims.

### Selective external examples

Choosing disputes after seeing their witness structure can inflate apparent success and interaction prevalence.

**Mitigation:** use the external case-selection protocol, freeze the candidate frame, publish exclusions, and retain no-witness, invalid, and strict-criterion failures.

### Missing protocol dimensions

A successful witness inside the exposed space does not show that unexposed differences were irrelevant to the original reports.

**Mitigation:** record omitted differences, return no-witness honestly, conduct schema sensitivity analyses, and frame the result as conditional.

### Data transformation errors

Converting an external paper or repository into a static grid can transpose rows, misalign models, or alter categorical rules.

**Mitigation:** content-address raw inputs, publish transformation code, assert endpoint reproduction, use independent spot checks, and preserve the full transformed grid.

## Statistical conclusion validity

### Pointwise intervals after subset search

A witness selected across many configurations does not inherit pointwise 95% coverage as a post-selection guarantee.

**Mitigation:** provide simultaneous analysis over a predeclared family and separate deterministic artifact claims from uncertainty-qualified claims.

### Wrong resampling unit

Resampling items does not capture run, checkpoint, grader, infrastructure, or deployment variation.

**Mitigation:** name the uncertainty unit explicitly and use repeated-run methods only when repeated runs exist.

### Dependence and clustering

Benchmark items may share templates, sources, or latent tasks beyond the declared strata, violating simple item-resampling assumptions.

**Mitigation:** preserve known clusters/strata, conduct cluster sensitivity analyses when metadata exists, and avoid population interpretations unsupported by the sampling design.

### Discrete conclusion instability

Small interval changes near zero can change a categorical label and therefore witness membership.

**Mitigation:** report effect and interval margins, simultaneous labels, threshold sensitivity, and robust membership rather than only one categorical answer.

### Multiple objectives

Trying cardinality, cost, effect distance, robustness thresholds, and conclusion rules until one gives a favorable witness creates another multiverse.

**Mitigation:** preregister the primary objective and publish complete registered sensitivity families.

### Repeated-run assumptions

Robust witness bounds require stable fixed-trial Bernoulli repetitions or another justified model. Adaptive stopping, silent retry, and selective failure removal break the interpretation.

**Mitigation:** freeze stopping and failure policies; report attempted runs; use exact fixed-trial bounds only when their assumptions apply.

### Conservative methods and low power

Bonferroni, Hoeffding, and Clopper–Pearson procedures can return no robust witness despite meaningful true probabilities.

**Mitigation:** report power/recovery separately from false certification, plan repetition counts prospectively, and consider sharper models only with justified assumptions.

## External validity

### Real model evaluations

Synthetic mechanism coverage does not establish performance on real model/harness disputes.

**Mitigation:** construct a representative frozen external case series with item-level or executable evidence where possible.

### Benchmark and model diversity

One harness grid or model family may not represent coding, reasoning, safety, tool use, multimodal, or long-context evaluations.

**Mitigation:** stratify external studies by evaluation domain and avoid pooled prevalence claims without a sampling frame.

### Temporal drift

Models, APIs, graders, browsers, and harnesses change. A witness can be revision-specific.

**Mitigation:** bind every source, evaluator, model, and application revision; rerun rather than silently transferring old witnesses.

### Publication availability

Static grids often omit failed runs, item outcomes, or protocol details.

**Mitigation:** grade evidence level, distinguish static from executable reconciliation, and refuse stronger inference when evidence is incomplete.

## Ecological and product validity

### Does WebMCP improve real investigation?

A semantic tool surface can be technically correct yet offer no advantage over a clear UI or notebook.

**Mitigation:** execute the preregistered WebMCP-versus-DOM comparison across multiple agents, disputes, and prompt families.

### Researcher workflow fit

Evaluation teams may prefer code pipelines, experiment trackers, or notebooks over a browser page.

**Mitigation:** make packages, CLIs, schemas, and certificates first-class; treat the UI as one client rather than the scientific authority.

### Interpretation by users

Users may mistake a minimum witness for a universal explanation or a hash for truth.

**Mitigation:** expose limitations adjacent to results, use distinct verification labels, and test comprehension with technically sophisticated users.

### Cost of complete grids

Exact full-landscape evaluation can be prohibitively expensive when each protocol run is costly.

**Mitigation:** distinguish proposal from proof, reuse published rows, support minimum-mode certificates where appropriate, and research sound structure-aware pruning.

## Reproducibility validity

### Author-controlled reproduction

CI and clean-clone runs executed by the project author or assistant are not independent replication.

**Mitigation:** publish exact inputs and instructions, solicit an external reproduction, preserve failures, and compare artifact hashes.

### Supply-chain variation

A lockfile does not fully eliminate registry, operating-system, Node, or GitHub Action changes.

**Mitigation:** capture environment, publish SBOM/attestations for releases, pin workflow actions more strongly, and use a container or reproducible system image where practical.

### Generated artifact drift

A generated JSON file can be stale relative to source even when tests pass.

**Mitigation:** regenerate artifacts in CI, hash them, compare or upload the exact outputs, and bind reports to repository HEAD.

## Security validity

### Prompt injection

Structured scientific data can still contain adversarial text that influences a probabilistic agent.

**Mitigation:** never make source text tool instructions, limit operations, and include live injection trials. Deterministic engine immunity does not prove agent immunity.

### Authentication gap

SHA-256 identities do not authenticate publishers.

**Mitigation:** future signatures or attestations need independent trust anchors and do not replace scientific replay.

### Resource exhaustion

Finite does not necessarily mean safe; `2^20` worlds or large repeated-run arrays can exhaust a browser or CI worker.

**Mitigation:** enforce explicit byte, row, dimension, trial, time, and memory limits at every ingestion boundary before accepting arbitrary public input.

## Overall boundary

The current branch materially strengthens correctness, falsifiability, and portable verification. Its dominant remaining threats are external-case selection, repeated real-run evidence, live-agent evaluation, authentication, and independent reproduction. Those cannot be resolved by adding more synthetic tests alone.
