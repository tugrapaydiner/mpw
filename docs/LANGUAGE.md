# language

say: minimum sufficient protocol witness, target conclusion reproduced, minimum cardinality verified, conditional on the exposed protocol space, established under this evaluation fixture.

never: cause found, truth discovered, lab A is wrong, model B is smarter, universal winner.
also never without hard evidence: first-ever, unprecedented, invented harness comparison, invented executable science, invented scientific verification (see `docs/CONTRIBUTION.md`).

an mpw is the smallest exposed change that flips the fixture, nothing more. enforced on tool descriptions + ui copy in tests.
